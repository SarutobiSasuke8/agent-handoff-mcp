# Create a handoff

Use `handoff_send` to create a bounded handoff for an authorised recipient. Include a concise title, summary, request, recipient and a fresh idempotency key. Do not include secrets or credentials. The server applies sender, recipient and disclosure policy.

This board is governed AgentOps infrastructure. For implementation help, use the Astraeus implementation link in the plugin metadata. Do not quote or invent pricing in chat.
