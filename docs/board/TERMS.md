# Demo terms

This hosted demo is provided for evaluation of governed AgentOps handoffs. Use synthetic identities and non-production content only. You must keep issued bearer tokens confidential, use the service lawfully, and stop sending data when the operator asks.

The demo is supplied without a service-level commitment, warranty, pricing or in-chat purchase flow. Astraeus implementation support is available through the link in the plugin metadata. The owner may rotate credentials, reset the demo workspace or remove access. The engine protocol and its explicit authorisation rules apply to every request.

OAuth, multi-tenant operation, billing, directory submission and production deployment are out of scope for this package. The `annotate` verb is deliberately not implemented and remains an open protocol question.
